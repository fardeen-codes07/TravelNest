# TravelNest

TravelNest is a full-stack travel accommodation platform where users can explore and discover places to stay, create and manage their own listings, upload property images, and share reviews and ratings.

## Live Demo

[Visit TravelNest](https://travelnest-lca9.onrender.com/listings)

## Features

- User registration and login
- Authentication and authorization
- Browse and explore accommodation listings
- View detailed property information
- Create, edit, and delete listings
- Upload images using Cloudinary
- Add, edit, and delete reviews
- Rating system
- Session management
- Flash messages
- MongoDB database integration
- Responsive user interface

## Getting Started

### Prerequisites

- Node.js
- MongoDB Atlas
- Cloudinary

### Installation

Clone the repository:

git clone https://github.com/fardeen-codes07/TravelNest.git

Navigate to the project:

cd TravelNest

Install dependencies:

npm install

Create a `.env` file in the root directory and add your MongoDB, Cloudinary, and session configuration.

Start the application:

node app.js

The application will run on:

http://localhost:8080

## Project Overview

TravelNest follows an MVC-based architecture with separate models, controllers, routes, views, middleware, and utility modules. MongoDB is used for storing application data, Cloudinary handles property image uploads, Passport.js manages authentication, and Connect-Mongo is used for session storage.

## Deployment

The application is deployed using Render, with MongoDB Atlas used for database management and Cloudinary used for image storage.
